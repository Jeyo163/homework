# Пакетный анализатор заказов (CSV Order Analyzer)

Консольное Python-приложение для автоматизированного пакетного анализа исторических данных о заказах из CSV-файлов.

## Функционал
- **Пакетная обработка:** Скрипт автоматически находит и обрабатывает все CSV-файлы в директории `data/`.
- **Фильтрация:** Анализируются только успешно доставленные заказы (`status == 'Delivered'`).
- **Расчет метрик:** Для каждого файла вычисляется общая выручка, средний чек и количество заказов.
- **Отказоустойчивость:** Устойчив к поврежденным структурам данных, пустым файлам и некорректным (текстовым) значениям в колонках стоимости.
- **Логирование:** Все критические ошибки при чтении файлов логируются в `logs/errors.log` без остановки работы всей программы.
- **Сводный отчет:** Результаты агрегируются в единую таблицу `reports/summary_report.csv`.

## Структура проекта
- `src/config.py` — конфигурационный файл (настройки путей, имена колонок, таргеты фильтрации).
- `src/analyzer.py` — бизнес-логика и класс `OrderAnalyzer`.
- `run.py` — главный запускающий скрипт приложения.
- `requirements.txt` — зависимости проекта (`pandas`).

## Запуск проекта
1. Установите зависимости: `pip install -r requirements.txt`
2. Положите CSV-файлы с данными в папку `data/`.
3. Запустите анализатор: `python run.py`
